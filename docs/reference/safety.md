# 安全边界

## 不要泄漏

- API key、GitHub token、服务器密码。
- `.env`、私有 config、会话原文。
- shell 输出里的敏感内容。
- Langfuse 或审计中的 prompt/tool 原文，除非用户明确开启。

## 文件边界

- 读工具默认只访问当前工作区和少量用户级 q-code 信任目录。
- 写工具限制在当前 cwd 内。
- `@file` 默认只能引用当前工作区内文件。

## Shell 边界

- shell 默认在当前 cwd 内执行。
- 跳出 cwd 需要显式配置。
- 长命令应设置超时或后台运行。
- 大输出会 spill 到本地目录，主上下文只拿摘要。

## 文档边界

文档站只写通用说明，不写本机密钥、本地私人路径、服务器凭据或真实请求正文。
